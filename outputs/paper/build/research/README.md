# Research evidence vault

This local, plain-Markdown vault supports the recruitment reanalysis. It adapts
HyperResearch's query preservation, source notes, competing-claim checks,
independent critique, and citation verification to the existing R workflow.
It is **not** an installation or execution of HyperResearch's Claude Code harness.

Method reference: [HyperResearch](https://github.com/jordan-gibbs/hyperresearch),
reviewed at commit `15010c5142244b88265f7abadf7b7aa1a8237fde` on 2026-09-08.
The repository's performance claims are not evidence for this ecological study.

Publications and local calculations are distinct evidence types. Papers drawing
on overlapping FIA inventories do not count as independent replications of the
Michigan calculations. Source notes record what was actually accessed; an
abstract is not represented as a full-text review. Raw public-source documents
and all record-level FIA observations remain outside the published report.

Search locally with `rg -n 'recruitment|reconcile|sampling' research/notes`.
No external account, new subscription, or research-data upload is required.
